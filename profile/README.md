# i-Educar

Organização do ecossistema **i-Educar**: espelhamento do core, documentação, integrações e **módulos sob demanda** para requisitos típicos de editais / termos de referência municipais.

**Site:** https://i-educar.github.io/ · identidade visual **Buriti** (azuis SME + modo escuro)

**Upstream do core:** [portabilis/i-educar](https://github.com/portabilis/i-educar)
